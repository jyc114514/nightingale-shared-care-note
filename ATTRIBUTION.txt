Nightingale attribution and license audit
=========================================

Audit date: 2026-08-26

This file records the direct runtime/development dependencies actually used by this repository.
Versions come from backend/requirements.lock and frontend/pnpm-lock.yaml or installed package
metadata in the verified local environment. No external model, API key, patient dataset, or
third-party visual asset is bundled. The AI demo uses an original deterministic fixture provider
by default, with an optional HTTPX-based DeepSeek V4 Flash adapter behind the redaction boundary.

License verification note
-------------------------

“Not declared in installed meta” is intentional: the local Python distribution metadata did not
provide a License field for those packages, so this file does not infer a license from memory or
from a non-audited source. Confirm the upstream distribution license before any redistribution or
commercial deployment. Transitive packages are pinned in the lockfiles; this direct audit is not a
replacement for a deployment-specific SBOM/license review.

Original work in this repository
---------------------------------

The Nightingale application code, synthetic fixtures, deterministic provider, optional DeepSeek
adapter, ranking logic,
archival policy, metadata-only SSE event boundary, typed bilingual dictionaries, Windows
PowerShell launcher, diagrams, and documentation in this repository are original project work for
the 72-hour prototype. Phase 8 adds no runtime dependency; live DeepSeek calls are opt-in only and
use the official OpenAI-compatible Chat Completions contract. No live API response or key is
bundled. No real patient information is included.
